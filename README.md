# AI Travel Planner

**Plan the whole trip together, from anywhere.**

Yatra AI is an AI-assisted travel planning app built for Indian travellers — everything is priced in ₹ and scheduled in IST. Tell it where you're starting from, where you want to go, your dates and budget, and it compares flights, trains and buses, shortlists stays, and puts together a day-wise itinerary you can share with friends via a trip code.

## Features

- **Destination discovery** — describe your city, month and budget and get destination suggestions that actually fit.
- **Flight, train & bus comparison** — every option is scored on price, duration and convenience, with IST departure times.
- **Day-wise itinerary** — an hour-by-hour plan tailored to your trip length, pace and interests.
- **Plan together** — share a trip code so friends anywhere can join and see the same plan.
- **My trips** — a dashboard of every trip you own or have joined, with route, dates, traveller count and total budget at a glance.

## Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/start) (file-based routing via TanStack Router) + React 19
- **Build tool:** Vite
- **Language:** TypeScript
- **Styling / UI:** Tailwind CSS v4, [shadcn/ui](https://ui.shadcn.com/) components on top of Radix UI primitives
- **Forms & validation:** React Hook Form + Zod
- **Data fetching:** TanStack Query
- **Backend / DB / Auth:** [Supabase](https://supabase.com/)
- **Package manager:** [Bun](https://bun.sh/)

## Project Structure

Routing follows TanStack Start's file-based conventions — every `.tsx` file under the routes directory defines a route:

| File                      | URL                              |
| -------------------------- | --------------------------------- |
| `index.tsx`                | `/`                                |
| `about.tsx`                | `/about`                           |
| `users/index.tsx`          | `/users`                           |
| `users/$id.tsx`            | `/users/:id` (dynamic segment)     |
| `posts/{-$category}.tsx`   | `/posts/:category?` (optional)     |
| `files/$.tsx`              | `/files/*` (splat route)           |
| `_layout.tsx`              | layout route (wraps children)      |
| `__root.tsx`               | app shell, wraps every page        |

`routeTree.gen.ts` is auto-generated by the router plugin — don't edit it by hand.

Other top-level folders:

```
├── public/        # Static assets
├── src/           # Application source (routes, components, etc.)
├── supabase/      # Supabase config / migrations / functions
```

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) installed
- A [Supabase](https://supabase.com/) project (for auth and data)

### Installation

```bash
git clone https://github.com/anshikasaini12/AI-Travel-Planner.git
cd AI-Travel-Planner
bun install
```

### Environment Variables

Create a `.env` file in the project root with your Supabase project credentials:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> Check `supabase/` for any additional configuration your instance requires.

### Run the dev server

```bash
bun run dev
```

### Other scripts

```bash
bun run build       # Production build
bun run build:dev   # Development-mode build
bun run preview     # Preview a production build locally
bun run lint         # Run ESLint
bun run format       # Format with Prettier
```
